# Readable native typography 0.4 — 2026-11-16

After confirming the larger keyboard worked, the owner requested clearer text. The app now uses locally installed IBM Plex Mono Medium TrueType glyphs with a shared baseline and grayscale alpha antialiasing. The old one-bit, independently top-aligned glyphs are no longer used by this app. Keyboard geometry from 0.3 is preserved.

Normal text uses 18 × 34 cells at font size 25; headings/keyboard characters use 28 × 52 cells at size 40. The terminal is 38 columns × 14 rows, increasing glyph size within the same display area above the keyboard. Labels are centered using the actual cell metrics; compact status strings avoid spilling between cards.

The font is rasterized on the workstation and compiled into the static ARM64 program. No runtime TrueType engine or font daemon is required on the phone. Raw TTF and generated alpha headers remain local build inputs and are not committed. Use LOCAL_TTF=/path/to/compatible-monospace.ttf to select another local font when rebuilding.

This improves raster typography; it does not implement a Unicode terminal. The present glyph repertoire and console remain printable ASCII/TERM=dumb. UTF-8 decoding, accented-character input and full terminal emulation are separate work.

Warning-clean ARM64 build, host sanitizer previews of all four views, actual PTY/key-dispatch tests, phone-native selftest and phone framebuffer readback passed. The owner confirmed 0.3 keyboard functionality; readability acceptance of 0.4 remains a manual observation. Wi-Fi remained connected during deployment.

The owner-private integrated candidate was rebuilt with this version: 25,088,376 bytes, original bootloader/DTBs/kernel retained. It has not been transferred or booted; older private candidates remain available.
